# Runtime image board constraints

`top_runtime_soc.xdc` maps the four `led` outputs to Zybo Z7-10 pins M14,
M15, G14 and D18, in increasing LED index order, with LVCMOS33 I/O standards.
The [top walkthrough](../rtl/top/top_runtime_soc.md) describes their status bits.

DDR and FIXED_IO constraints come from the Zynq processing-system IP and board
preset. FCLK_CLK0 is configured at 100 MHz by
[the runtime block design](../scripts/bd/top_runtime_soc.md); its clock constraint
is generated by the PS IP. The XDC deliberately does not add a competing primary
clock, timing exceptions, or DRC severity overrides.

Only the runtime standalone build selects this file. Pin-string regression checks
are not physical implementation verification: inspect routed timing and DRC
reports before considering a build usable. No board programming is performed by
these constraints or the build scripts.
